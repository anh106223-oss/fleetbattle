# Fleet Battle — Bấm Nút Run Trên VS Code Là Chơi Ngay!

## Cách 1: Bấm F5 hoặc nút ▶ Run trong VS Code (Khuyên dùng)
1. Giải nén file `fleet-battle-vscode.zip`.
2. Mở VS Code → **File** → **Open Folder...** → chọn thư mục vừa giải nén.
3. Nhấn phím **F5** (hoặc chọn tab **Run and Debug** bên trái rồi bấm nút **▶ Chạy Web Fleet Battle**).
4. Lần đầu sẽ tự động chạy `npm install`, sau đó **tự động mở trình duyệt web vào thẳng game**!

## Cách 2: Mở file `CHAY_WEB_NGAY.py` và bấm nút ▶ ở góc trên phải
1. Mở file `CHAY_WEB_NGAY.py` trong VS Code.
2. Bấm nút **▶ (Run Python File)** ở góc trên bên phải trình soạn thảo.
3. Trình duyệt web sẽ tự động bật lên tại `http://localhost:3000`.

## Cách 3: Chạy riêng Engine AI Python trên Terminal
Mở file `python_ai/fleet_battle_ai.py` và bấm nút **▶** để đấu trực tiếp với 5 cấp độ AI ngay trong Terminal VS Code (không cần Node.js).
